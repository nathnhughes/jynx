# Security policy

## Supported versions

Only the latest release of jynx gets security fixes.

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through [GitHub private vulnerability reporting](https://github.com/nathnhughes/jynx/security/advisories/new) instead.

Include the jynx version, the steps to reproduce and the impact you expect. You should get a reply within a week.
